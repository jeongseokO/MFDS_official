# MFDS Korean-English Parallel Corpus

## 1. 데이터 개요

본 데이터는 의약품 규제 문서를 기반으로 구축한 한·영 병렬 말뭉치입니다.  
한국어 원문과 이에 대응하는 영어 번역문을 문장 또는 구간 단위로 정렬하여 구성하였습니다.

## 2. 데이터 다운로드

데이터는 아래 Google Drive 링크를 통해 다운로드할 수 있습니다.

- **파일명**: `MFDS_parallel_corpus_v1.0.zip`
- **다운로드 링크**: https://drive.google.com/drive/folders/1OeV28JyZcU-rVJkEYelK-zPTad75hqgN?usp=drive_link

> 다운로드 권한이 없는 경우 서울대학교 CCADD 연구팀으로 문의해 주시기 바랍니다.
