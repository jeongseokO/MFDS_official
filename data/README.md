# MFDS Korean-English Parallel Corpus

## 1. 데이터 개요

본 데이터는 의약품 규제 문서를 기반으로 구축한 한·영 병렬 말뭉치입니다.
한국어 원문과 이에 대응하는 영어 번역문을 문장 또는 구간 단위로 정렬하여 구성하였습니다.

## 2. 파일 정보

* 파일명: `MFDS_parallel_corpus_v1.0.zip`
* 버전: v1.0
* 데이터 형식: JSON
* 언어: 한국어-영어
* 압축 형식: ZIP
* 구축 기관: 서울대학교 CCADD
* 최종 업데이트: 2026-07-30

## 3. 데이터 구성

압축 파일에는 다음과 같은 데이터가 포함되어 있습니다.

```text
MFDS_parallel_corpus_v1.0/
├─ KE/
│  └─ 한국어-영어 병렬 말뭉치
├─ metadata/
│  └─ 문서 및 데이터 출처 정보
└─ README.txt
```

각 데이터 레코드는 다음 항목으로 구성됩니다.

* `document_id`: 문서 식별자
* `segment_id`: 문장 또는 구간 식별자
* `ko_txt`: 한국어 원문
* `en_txt`: 영어 번역문
* `source`: 데이터 출처
* `metadata`: 문서 관련 부가 정보

## 4. 데이터 활용 시 주의사항

* 본 데이터는 연구 및 과제 수행을 위한 공유 자료입니다.
* 데이터의 재배포 및 외부 공개는 사전 협의가 필요합니다.
* 원문 문서의 저작권과 이용 조건을 확인한 후 사용해야 합니다.
* 개인정보, 비공개 정보 및 민감정보가 포함되지 않았는지 확인 후 활용해야 합니다.
